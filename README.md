# 📦 자재 구매 내역 관리

로컬에서 돌아가는 자재 거래 대장임. 서버 없고 DB 없고 그냥 브라우저 하나면 됨.  
엑셀 켜기 귀찮아서 만들었음.

---

## 이게 뭐임?

회사에서 자재 사올 때마다 "뭘 얼마에 몇 개 샀는지" 기록하는 프로그램임.  
`index.html` 더블클릭하면 바로 실행됨. 설치 같은 거 없음.

데이터는 브라우저 localStorage에 저장되니까 인터넷 끊겨도 상관없음.  
단, **브라우저 계정(프로필)이 다르면 데이터가 안 보임.** 이건 브라우저 구조라 어쩔 수 없음. CSV 백업해두면 해결됨.

---

## 주요 기능

### 📝 거래 등록
- 날짜 한 번 설정하고 품목을 줄줄이 추가하는 **영수증 스타일** 입력
- 날짜는 숫자만 치면 자동으로 `2026-05-22` 형태로 변환해줌
- 품목별 수량 × 단가 = 총액 **실시간 자동 계산**
- 비고란 있음. 메모 적고 싶으면 적으면 됨

### 🔍 검색 & 조회
- 상단 검색창에 **여러 단어를 띄어쓰기나 쉼표로** 같이 치면 교집합(AND) 검색됨
  - 예: `멀티탭 1500` → 멀티탭이면서 1500이 포함된 항목만 쏙
- 품목명, 날짜, 단가, 비고 전부 검색 대상임
- 날짜 정렬 (오름차순/내림차순) 가능

### 📄 페이지네이션
- 20개씩 끊어서 페이지로 나눠줌
- 현재 페이지 / 전체 페이지 표시됨
- 원하는 페이지 번호 직접 입력해서 점프 가능

### ✏️ 수정 & 삭제
- 각 항목마다 수정/삭제 버튼 있음
- 수정 누르면 해당 행이 입력칸으로 바뀜 → 고치고 저장하면 끝
- 날짜, 품목명, 수량, 단가, 비고 전부 수정 가능

### 💾 CSV 백업 & 복원
- **CSV 백업**: 현재 데이터를 `.csv` 파일로 다운로드. 엑셀에서 열어볼 수도 있음
- **CSV 복원**: 백업해둔 `.csv` 파일을 다시 불러옴
- 복원할 때 **스마트 병합 4가지 옵션** 제공:
  1. 비고란만 복구 (단가/수량은 현재 유지)
  2. 단가/수량 업데이트 (비고란은 현재 유지)
  3. 단순 이어붙이기
  4. 완전 덮어쓰기

### ↩️ 되돌리기 (Undo)
- CSV 복원 후 "아 잘못 넣었다" 싶으면 **직전 복원 취소** 버튼으로 원상복구 가능
- 버튼은 복원한 적 있을 때만 나타남

## 알아둘 것

- **저장 용량**: localStorage는 브라우저마다 다르지만 보통 5~10MB임. 수천 건 정도는 거뜬한데 만 건 넘어가면 CSV로 백업하고 오래된 거 정리하는 게 좋음
- **브라우저 프로필**: 크롬 회사 계정이랑 개인 계정은 localStorage가 따로임. 데이터 옮기려면 CSV 백업 → 다른 프로필에서 복원하면 됨
- **바탕화면 바로가기**: 바로가기 만들어도 됨. 근데 원본 파일 경로가 바뀌면 localStorage 데이터 못 찾을 수 있으니 파일 위치는 고정해두는 게 좋음
